## 2. 生命周期

```
__init__()
  ├─ _init_config()     配置加载 → 验证 → Pydantic
  ├─ _init_services()   StateManager + CloudSyncService + NamingValidator + NotifyService
  └─ _start_sync_loop() asyncio.create_task(_sync_loop())

initialize()
  ├─ 延迟初始化 handlers
  └─ 预热: 从 NextCloud 拉取远程文件信息写入 SQLite 查重表

terminate()
  ├─ _running = False → cancel _sync_task
  └─ state_manager.close()
```

- **开关**: `sync_enabled=false` → `_sync_loop()` 完全不启动，手动命令也拒绝
- **循环控制**: `self._running` 控制 while 循环退出

## 3. 同步触发方式

### 3.1 定时同步

```
_sync_loop() → while _running:
    sync_all_groups()
    get_next_delay_seconds() → asyncio.sleep()
```

两种调度模式:

| 模式 | 配置 | 行为 |
|------|------|------|
| 时间点 | `sync_time_points=["08:00","12:00"]` | 到点触发，跨夜自动滚动 |
| 间隔 | `sync_interval_minutes=1440` | 固定间隔（默认 24h） |

### 3.2 手动触发

- `/同步文件` → `sync_all_groups()`

### 3.3 sync_all_groups

```
sync_all_groups():
    for group_id in enabled_groups:
        sync_group(group_id)
    process_retry_queue()
```

## 4. 单群同步流程

```
sync_group(group_id):
  ① get_group_info()          → (群名称, 群号)
  ② get_last_sync_time()      → 上次同步时间
  ③ _get_group_files()        → FileScanner.list_files()
  ④ 遍历文件 → 五层过滤
  ⑤ 查询群绑定预设路径        → state_manager.get_group_binding()
  ⑥ generate_target_path()    → 生成云盘路径
  ⑦ _sync_single_file()       → SyncExecutor.sync_single_file()
  ⑧ update_last_sync_time()   → 更新 SQLite
```

## 5. 五层过滤机制

| 层级 | 条件 | 命中场景 |
|------|------|---------|
| 1. 文件类型 | `is_file_type_allowed(file_name)` 返回 False | 扩展名不在白名单 |
| 2. 时间戳 | `upload_time <= last_sync_time` | 上次同步前的旧文件 |
| 3. file_id 去重 | `is_synced(file_id)` 返回 True | 已通过 file_id 同步过 |
| 4. name+size 去重 | `is_synced_by_name_size(name, size, gid)` 返回 True | 同名同大小的文件已同步 |
| 5. 命名规范 | `naming_validator.parse()` 返回 `is_valid=False` 且分类 ≠ 数据组测试 | 不合规且非测试文件 |

## 6. 单文件同步流程

```
SyncExecutor.sync_single_file():
  ① _analyze_naming(file_name)     → NamingResult (命名规范分析)
  ② FileDownloader.download_file() → (success, local_path, error_stage, error_detail)
  ③ CloudSyncService.upload_file_direct() → (success, error_stage, error_detail)
  ④ FileDownloader.cleanup()       → 删除本地临时文件
  ⑤ 返回 SyncResult (success / failed_stage / naming_* )
```

**SyncResult 包含**:
- `success`: 是否成功
- `failed_stage`: 失败阶段枚举值
- `failed_detail`: 失败详情（HTTP 状态码、异常消息等）
- `naming_*`: 命名规范分析结果（分类/项目/版本/合规性）

### 失败阶段枚举

| 阶段 | failed_stage | 说明 |
|------|-------------|------|
| 下载 | `download_no_url` | 无法获取下载链接 |
| 下载 | `download_http_error` | HTTP 状态错误 |
| 下载 | `download_network_error` | HTTP 连接/超时 |
| 下载 | `download_size_mismatch` | 文件大小不匹配（不完整） |
| 下载 | `download_file_missing` | 文件未写入本地 |
| 上传 | `upload_local_missing` | 本地文件不存在 |
| 上传 | `upload_mkdir_failed` | 目录创建失败 |
| 上传 | `upload_http_error` | 上传 HTTP 错误 |
| 上传 | `upload_timeout` | 上传超时 |
| 上传 | `upload_network_error` | 连接错误 |
| 平台 | `sync_no_platform` | 无法获取 QQ 平台 |
| 异常 | `sync_exception` | 未知异常 |

## 7. 下载阶段

```
FileDownloader.download_file(group_id, file_id, file_name, file_size):

  ① get_file_url()           → FileScanner.get_file_url()
  ② httpx.AsyncClient.stream("GET", url)
  ③ 64KB chunk 流式写入本地临时目录
  ④ 每 10MB 输出进度日志
  ⑤ 校验: local_path.exists() + actual_size == file_size
  ⑥ 大小不匹配 → 删除不完整文件 + 返回失败
```

**超时**: `max(600s, file_size/MB * 15s)` — 至少 10 分钟，每 MB 加 15 秒

**临时目录**: `{系统临时目录}/file_sync/{文件名}`

## 8. 上传阶段

```
CloudSyncService.upload_file_direct(local_path, remote_path, file_size):

  ① 检查本地文件存在 → 否则 return upload_local_missing
  ② 检查远程文件存在 → 冲突时自动重命名 (+时间戳后缀)
  ③ ensure_directory_exists(dir_path) → 逐层 MKCOL
  ④ httpx.Client.put(url, content=f)  → WebDAV PUT (在 asyncio.to_thread 中)
  ⑤ 失败重试: HTTP 错误等 10s，超时等 30s，最多 3 次
```

**重命名规则**: `{原文件名}_{YYYYMMDD_HHMMSS_ffffff}{扩展名}`

## 9. 重试队列

```
process_retry_queue():
  get_pending_retries()          ← WHERE next_retry <= now
  for item in pending:
    item.attempts >= retry_max_attempts (默认3)?
      → remove + _notify_retry_failed() (发送群消息)
    else:
      → _sync_single_file()
        成功 → remove + add_sync_record
        失败 → 保持队列 (attempts 累加)
```

**SQLite 结构**:
```sql
retry_queue (
    file_id TEXT UNIQUE,
    attempts INTEGER,
    next_retry TEXT,     -- ISO 格式
    ...
)
```

## 10. 文件名事件检查

```
用户上传文件 → GROUP_MESSAGE 事件
  → FileEventHandler.handle_file_upload()
    → 检查: filename_check_enabled + 群号在 enabled_groups 中
    → 从消息链提取 File 组件 → filename
    → NamingValidator.validate(filename)
    → 不合规 → NotifyService.build_message_chain() → @提醒
    → 合规但 deprecated → 温和迁移提醒
```

### 提醒消息格式

**不合规**:
```
@用户 你上传的文件「xxx.pdf」格式不规范
问题：
  · 缺少分隔符，请使用格式：项目名称-分类v版本号-后缀.扩展名
正确格式：项目名称-分类v版本号-后缀.扩展名
可用分类：封面、成片、素材、音频、字幕、数据组测试
👉 正确格式：你的项目名-分类v1-后缀.pdf
   例如：xxx-成片v1.pdf 或 xxx-素材.pdf
```

**deprecated 温和提醒**:
```
@用户 你上传的文件「素材--项目1.pdf」使用了旧格式「分类--名称」
⚠️ 该格式仍被接受，但建议迁移到新格式：项目名称-分类v版本号-后缀
👉 建议改为：素材-项目1-v1.pdf
```

## 11. 命名规范

### 新格式（推荐）

```
{项目名称}-{分类}[v{版本号}][-{后缀}].{扩展名}
```

**示例**:
| 文件名 | 分类 | 版本 | 后缀 |
|--------|------|------|------|
| 项目A-视频封面v1.png | 封面 | 1 | — |
| 项目A-成片v2-无字幕.mp4 | 成片 | 2 | 无字幕 |
| 播客-录音v1-处理v1.flac | 音频 | 1 | 处理v1 |
| 项目C-字幕v1.ass | 字幕 | 1 | — |

### 旧格式（兼容，deprecated）

```
{分类}--{名称}.{扩展名}
```

### 六大标准分类

| 分类 | 关键词 | 允许扩展名 |
|------|--------|-----------|
| 封面 | 封面 | png, jpg, jpeg, psd |
| 成片 | 成片/成品/预览 | mp4, zip, rar, 7z |
| 素材 | 素材 | 通用图片/视频/文档/压缩包 |
| 音频 | 录音/音频 | wav, flac, mp3, aac, ogg, wma, m4a, zip, rar, 7z |
| 字幕 | 字幕 | ass, srt, vtt, ssa, zip, rar, 7z |
| 数据组测试 | 数据组测试 | 无限制 |

### 工程后缀

匹配: `工程` / `工程v2` / `工程-PR2022` / `工程v2-PR`

- 成片 + 工程后缀 → 上传到 `{路径}/成片/工程/`
- 音频 + 工程后缀 → 上传到 `{路径}/音频/工程/`
- 封面/素材/字幕 → 工程后缀不产生二级目录

## 12. 目标路径生成

```
generate_target_path(group_name, group_id, filename, category, project_name, preset_base):

  ① 有 preset_base (群绑定了预设路径):
     path = {preset_base}/{分类}[/工程]/{文件名}

  ② 无 preset_base (回退):
     path = {base_path}/{group_name}_{group_id}/{分类}[/工程]/{文件名}
```

**示例**:

| 文件 | 群绑定 | 生成路径 |
|------|--------|---------|
| 项目A-成片v1.mp4 | /客户/项目A | `/客户/项目A/成片/项目A-成片v1.mp4` |
| 项目A-成片v2-工程-打包.zip | /客户/项目A | `/客户/项目A/成片/工程/项目A-成片v2-工程-打包.zip` |
| 未知-成片v1.mp4 | 无 | `/QQ群文件/群名_123456/成片/未知-成片v1.mp4` |

## 13. 预设路径与群绑定

### SQLite 表结构

```sql
preset_paths (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE,
    remote_path TEXT NOT NULL,
    created_at TEXT NOT NULL
);

group_bindings (
    group_id TEXT PRIMARY KEY,
    path_id INTEGER NOT NULL,
    bound_at TEXT NOT NULL,
    FOREIGN KEY (path_id) REFERENCES preset_paths(id)
);
```

### 命令

| 命令 | 功能 | 校验 |
|------|------|------|
| `/预设路径` / `/预设路径 列表` | 列出所有预设路径（含绑定群） | — |
| `/预设路径 添加 <名称> <NextCloud路径>` | 添加预设路径 | WebDAV 校验路径存在 |
| `/预设路径 删除 <名称>` | 删除（有绑定时阻止） | — |
| `/绑定路径 <群号> <路径名称>` | 绑定群到预设路径 | — |
| `/解绑路径 <群号>` | 解除绑定 | — |
| `/绑定列表` | 列出所有绑定关系 | — |

### 安全开关

群同步需要**同时满足**两个条件:
1. `group_id` 在 `enabled_groups` 列表中
2. `group_id` 在 `group_bindings` 表中有绑定记录

移除 `enabled_groups` 可快速关停某群同步，无需解绑。
