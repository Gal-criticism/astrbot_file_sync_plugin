# QQ群文件自动同步NextCloud插件设计

## 1. 概述

**功能**: 定时扫描QQ群文件夹，将群文件自动同步到NextCloud私有云盘

**方案**: 方案B - 监控群文件夹（定时扫描 + OneBot API）

---

---

## 3. 模块划分

### 3.1 FileSyncPlugin (主类)
- 继承 `Star` 类
- 管理生命周期和配置
- 注册命令和定时任务

### 3.2 FileScanner (文件扫描器)
- 调用 `get_group_file_list` 获取群文件列表
- 与同步状态比对，找出新增/修改的文件
- 支持文件大小和类型过滤

### 3.3 CloudSyncService (云盘同步服务)
- 封装 `nc_py_api` 操作
- 实现文件上传、目录创建
- 处理重命名逻辑（时间戳防重）

### 3.4 SyncStateManager (状态管理器)
- 记录已同步文件（本地SQLite）
- 存储文件hash、群号、文件名、同步时间
- 支持增量同步

## 5. 配置项设计

```json
{
  "nextcloud_url": "https://your-nextcloud.example.com",
  "nextcloud_username": "bot_user",
  "nextcloud_password": "app_password",
  "group_mappings": {
    "123456789": "/QQ群文件/游戏群",
    "987654321": "/QQ群文件/工作群"
  },
  "sync_interval_minutes": 5,
  "file_type_whitelist": [".pdf", ".docx", ".xlsx", ".zip", ".jpg", ".png", "*"],
  "notify_on_success": false,
  "notify_on_error": true,
  "retry_queue_enabled": true,
  "retry_max_attempts": 3,
  "retry_delay_seconds": 300
}
```

**配置说明**:
| 配置项 | 说明 |
|--------|------|
| `nextcloud_url` | NextCloud WebDAV地址 |
| `nextcloud_username` | NextCloud用户名 |
| `nextcloud_password` | NextCloud应用密码 |
| `group_mappings` | 群号到云盘路径的映射 |
| `sync_interval_minutes` | 同步间隔（分钟） |
| `file_type_whitelist` | 允许同步的文件类型（`*`表示所有类型） |
| `retry_queue_enabled` | 失败是否加入重试队列 |
| `retry_max_attempts` | 最大重试次数 |
| `retry_delay_seconds` | 重试间隔（秒） |

## 6. 文件重命名逻辑

当云盘存在同名文件时，自动重命名：

```
原文件名: 文档.docx
重命名后: 文档_20260423_143052.docx
```

格式: `{原文件名}_{年月日}_{时分秒}.{扩展名}`

---

## 7. 错误处理

| 场景 | 处理方式 |
|------|---------|
| NextCloud连接失败 | 记录日志，加入重试队列 |
| 文件下载失败 | 记录日志，加入重试队列，稍后重试 |
| 群文件列表获取失败 | 记录日志，跳过该群 |
| 文件类型不允许 | 跳过并记录 |
| 同步失败 | 加入重试队列，最多重试3次，间隔5分钟 |
| 同步完成 | 可选通知管理员 |

## 8. 命令接口

| 命令 | 说明 |
|------|------|
| `/同步文件` | 手动触发一次同步 |
| `/同步状态` | 查看当前同步状态 |
| `/同步统计` | 查看同步统计信息 |

---

## 9. 技术栈

- **AstrBot插件框架**: 继承Star类，使用@filter装饰器
- **定时任务**: APScheduler (AsyncIOScheduler)
- **NextCloud客户端**: nc_py_api
- **本地状态**: SQLite
- **协议层调用**: aiocqhttp OneBot API

- [x] 群文件删除 → **不同步删除云端文件**
- [x] 同步失败 → **加入重试队列，最多重试3次，间隔5分钟**
