# 项目文件管理与命名规范（260627）
## 一、封面文件
### 命名示例
1. 项目名称-视频封面v1
2. 项目名称-视频封面v1-16-9
3. 项目名称-文章封面v1
4. 项目名称-视频封面v1-工程
### 格式备注
普通封面：png、jpg格式；封面工程：psd格式

## 二、成片文件
### 命名规范
1. 项目名称-成片v1-无字幕
2. 项目名称-成片v2-字幕v1
3. 项目名称-预览v1-无字幕
### 格式要求
统一为mp4格式
### 存放规则
该文件夹仅存放完整成片、预览；文件名必须包含「成片」「成品」或「预览」，并标注有无字幕。
### 版本规则
1. 成片版本号与预览版本号保持一致：成片v1对应预览v1，内容完全一致；成片有修改则版本号升级为成片v2。
2. 字幕版本独立更新，仅字幕内容改动时升级版本，与成片版本无关。

### 成片-工程子文件夹
#### 命名示例
1. 项目名称-成片v1-工程
2. 项目名称-成片v1-工程v2
3. 项目名称-成片v1-工程-PR2022
#### 格式
zip、rar、7z等压缩包格式
#### 备注
1. 成片v1-工程：对应成片v1的源工程文件。
2. 工程仅改动、成片无需重新导出（重新打包、适配旧版软件等场景），可标注工程v2、软件版本后缀（如PR2022）。

## 三、素材
定义：除项目成片、项目封面以外的图片、视频文件。

## 四、音频文件
### 命名规范
1. 项目名称-录音v1
2. 项目名称-XX录音v1（XX为录音者ID，多人节目专用）
3. 项目名称-XX录音v1-处理v1
4. 项目名称-录音v1-剪辑v1
5. 项目名称-音频v1
6. 项目名称-音频v1-处理v1
### 格式
基础无损音频：wav、flac；嘉宾录音有损格式：mp3、aac
### 两类制作流程
1. 传统流程（音频剪辑导向）：录音 → 录音处理 → 录音剪辑 → 添加音乐音效及处理（成品）
2. 实验流程（视频演出导向）：录音 → 录音处理 → 视频剪辑（导出音频）→ 视频音频处理（成品）
### 名词释义
- 录音：无背景音乐、音效的纯人声文件
- 音频：完成剪辑、叠加音乐音效的成品/半成品音频

### 音频-工程子文件夹
1. 命名规则：对应输出音频文件名 +「-工程」后缀
2. 格式：zip、rar、7z压缩包
